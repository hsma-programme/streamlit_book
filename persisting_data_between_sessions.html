39  Persisting data between sessions


Streamlit apps deployed on something like Streamlit Community Cloud, or on a platform like Heroku, run on temporary storage. Data you write to a file (e.g. a CSV) in a folder alongside your app will not persist indefinitely. It can be lost whenever the app restarts, redeploys or goes to sleep.

If your app needs to save data, you need a place to read and write from outside the app itself.


39.1 Which option should I use?

Option Best for Setup effort
Google Sheets Small, simple datasets that non-coders also need to view or edit Low (public) / Medium (private or writing)
Supabase Proper relational data (PostgreSQL) with a free tier Medium
TiDB Cloud MySQL-compatible hosted database Medium
Internal database Internal tools on organisational infrastructure Depends on your IT team

Streamlit has tutorials for many other sources (AWS S3, BigQuery, MongoDB, Neon, PostgreSQL, Snowflake and more): https://docs.streamlit.io/develop/tutorials/databases

Warning

Never commit credentials to GitHub. Keep them in .streamlit/secrets.toml locally, add that file to .gitignore, and paste its contents into Settings > Secrets (or “Advanced settings” when first deploying) on Community Cloud.


39.2 Google Sheets

You can use the st-gsheets-connection package alongside st.connection to interact with Google Sheets.

Package: https://github.com/streamlit/gsheets-connection

Tip

If deploying to community cloud, you will need to provide a requirements.txt file containing the following line (plus any other packages you require):

st-gsheets-connection

39.2.1 Reading a public sheet

This app shows an example of reading from a google sheet:

https://hsma-g-sheets-app-read.streamlit.app/

Set the sheet’s sharing to “Anyone with the link” as Viewer. Anyone with the link can see all the data, so treat the link like a password.

Put the URL in .streamlit/secrets.toml. When deploying this to the community cloud, you click into ‘advanced settings’ when deploying your app and paste the contents of the secrets file there.

Example secrets file:

test_secret = "llama"

[connections.gsheets]
spreadsheet = "https://docs.google.com/spreadsheets/d/1IrzMP1httjxBFOSmTQGKg-V7Uzpw06YkPCeP7YimSQE/edit?usp=sharing"

App code:

import streamlit as st
from streamlit_gsheets import GSheetsConnection

# Confirm access to the secrets file
st.write("The secret word is:", st.secrets["test_secret"])

# Create a connection object.
conn = st.connection("gsheets", type=GSheetsConnection)

# Passing in 'Sheet1' returns a '400 resource not found error'
# Passing in the index of the sheet as an integer works!
df = conn.read(worksheet=0)

st.dataframe(df)

from streamlit_gsheets import GSheetsConnection
import random
import numpy as np
import pandas as pd
from datetime import datetime
# would need to be installed with
# !pip install st-gsheets-connection

# Confirm access to the secrets file
st.write("The secret word is:", st.secrets["test_secret"])

# Create a connection object.
conn = st.connection("gsheets", type=GSheetsConnection)

# Passing in 'Sheet1' returns a '400 resource not found error'
# Passing in the index of the sheet as an integer works!
df = conn.read(worksheet=0, ttl=0)
st.dataframe(df.sort_values("Added", ascending=False))

if st.button("Update worksheet"):
    # Update the dataframe before overwriting in case any actions have been undertaken since the user first loaded the page
    df = conn.read(worksheet=0, ttl=0)

    # Generate an additional data field
    units = random.randint(100, 5000)
    unit_cost = np.round((random.random() + random.randint(1, 10)), 2)

    additional_row = [
        {'Item': "Additional HSMA Merchandise",
        "Category": random.choice(["Stickers", "Pets", "Clothing", "Mugs"]),
        "Units": units,
        "Unit Cost": unit_cost,
        "Total": units * unit_cost,
        "Added": datetime.now().strftime("%d/%m/%Y %H:%M:%S")
        }
    ]

    df_updated = pd.concat(
        [df,
        pd.DataFrame(additional_row)
        ]
    )

    df = conn.update(
        worksheet=0,
        data=df_updated,
    )
    st.cache_data.clear()
    st.rerun()

39.3 Supabase

Supabase is an open source, PostgreSQL-based database service. Streamlit connects to it with st.connection and the community-built st-supabase-connection library.

39.3.1 Setup

  1. Sign up at Supabase, create a project, and note down the Project URL and API key.
  2. Create a table, for example in the SQL editor:
CREATE TABLE mytable (
    name varchar(80),
    pet varchar(80)
);

INSERT INTO mytable VALUES ('Mary', 'dog'), ('John', 'cat'), ('Robert', 'bird');
  1. Add your credentials to .streamlit/secrets.toml:
[connections.supabase]
SUPABASE_URL = "xxxx"
SUPABASE_KEY = "xxxx"
  1. Add the library to requirements.txt, ideally pinning the version:
st-supabase-connection==x.x.x

App code:

import streamlit as st
from st_supabase_connection import SupabaseConnection

# Initialise connection
conn = st.connection("supabase", type=SupabaseConnection)

# Query (cached for 10 minutes; use ttl=0 to disable caching)
rows = conn.query("*", table="mytable", ttl="10m").execute()

for row in rows.data:
    st.write(f"{row['name']} has a :{row['pet']}:")
Tip

You can also use the official supabase Python client directly (wrapping it in st.cache_resource/st.cache_data), or use the PostgreSQL connection string from Supabase’s settings with st.connection("...", type="sql"). See the Streamlit Supabase tutorial.


39.4 TiDB cloud

TiDB is an open-source, MySQL-compatible database. TiDB Cloud is the fully managed service, with a free tier. The example below needs Streamlit 1.28 or later.

39.4.1 Setup

  1. Sign up for TiDB Cloud and open your cluster. Click Connect to get the connection details, then Generate Password. Note the password down, because it is not shown again.
  2. Create your database and table (via the SQL Editor or a mysql client).
  3. Add the details to .streamlit/secrets.toml:
[connections.tidb]
dialect = "mysql"
host = "<TiDB_cluster_host>"
port = 4000
database = "pets"
username = "<TiDB_cluster_user>"
password = "<TiDB_cluster_password>"
  1. Add dependencies to requirements.txt:
mysqlclient==x.x.x
SQLAlchemy==x.x.x

39.4.2 App code

import streamlit as st

conn = st.connection("tidb", type="sql")

df = conn.query("SELECT * FROM mytable;", ttl=600)

for row in df.itertuples():
    st.write(f"{row.name} has a :{row.pet}:")

39.5 Writing to an internal database

For an internal tool that is deployed on internal server infrastructure, you may wish to write to an existing database in your organisation.

Streamlit provides details around how to do this with a range of providers, such as Microsoft SQL Server

Details for different databases can be found here: https://docs.streamlit.io/develop/tutorials/databases

Speak to your IT or information governance team about access, credentials and what data can be stored.
